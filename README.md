# 🎬 Movie Recommendation System

A content-based movie recommendation system that suggests movies based on their genres, keywords, plot descriptions, cast, and directors.

## Features
- Recommends five similar movies.
- Uses natural language processing and text preprocessing.
- Uses CountVectorizer for text feature extraction.
- Uses Cosine Similarity to calculate movie similarity.
- Interactive web interface built with Streamlit.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- NLTK
- Streamlit
- Pickle

## Dataset
TMDB 5000 Movie Dataset from Kaggle.

## How to Run

1. Install the required libraries:
   `pip install pandas numpy scikit-learn nltk streamlit`

2. Navigate to the project directory.

3. Run:
   `streamlit run app/app.py`

4. Select a movie and click Recommend Movies.
